# Approximating Peak Prevalence in Multistage SIR Epidemics
This repository provides scripts to produce the panel plot in figure 3 of the 
manuscript "Approximating Peak Prevalence in Multistage SIR Epidemics" by Tverskoi et al.

Functions.py contains all necessary functions to calculate and plot bias for the simple, fully corrected, and 
large lambda one-step corrected approximations for peak prevalence. Main.py runs the script. 

Download files and run main.py. Within main.py, change values within r0_vect and k_vect or change epsilon and 
gamma values to calculate and plot bias of the estimates under different simulation scenarios.

The code was tested on Dell XPS15 running Windows 11 with PyCharm version 2026.1.2 and Python version 3.12
